## 规矩

- 表格用 GFM 语法（`| a | b |`），构建脚本靠它生成 Word 表格；**不要在单元格里写裸竖线**。
- 数值以公式为准，表值只是速查：改公式要同步 `game/public/data/config.json` 与 `game/tests/balance.test.ts`，否则「设计书 = 代码」这条断言会红。
- 内容红线（`01_overview.md` 1.5 节）是不可协商项，改编时不要碰。
- 改完重建后，`game/tools/` 之外没有自动检查 docx 的手段——用 office 技能里的校验脚本或人工翻一遍新加的部分。
- **章节号是全文唯一的编号体系**：引用一律写「第 X 章」「X.Y 节」，改编号时全库搜索旧号（`6.`、`7.`、`8.`、`9.`），但别用正则批量替换小数——`×6.7`、`8.33` 这类数值会被误伤（踩过）。
- **表格宽度由 `build_docx.py` 的 `table()` 统一算**：固定布局（`tblLayout=fixed`）+ 显式 `tblGrid`，可用宽度 = 版心 16.8 cm 减去每格左右内边距（各 80 dxa，即每列再扣 160 twips）。以前写成 `autofit=True` 且列宽不扣内边距，6 列表格最右边一列会被顶出页面。要调表格样式只改这一个函数。
