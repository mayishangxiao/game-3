### 6.1.1 三品质的取色方案（解决"紫色不在调色板"的问题）

白 / 蓝 / 紫三品质由 `config.json` 的 `quality_multiplier` 定义，但紫不在 24 色内。解决方案：**用两色组合 + 描边制造"紫感"，不新增色号。**

| 品质 | 底色 | 高光 | 描边 | 附加效果 |
| --- | --- | --- | --- | --- |
| 白 | `#C2BCD1` | `#F2EDE4` | `#6B6489` | 无 |
| 蓝 | `#2F6BA8` | `#7FB2D9` | `#1B3A6B` | 无 |
| 紫 | `#4A4468` | `#948DAB` | `#0D0B14` | 外发光 1 px（`#948DAB`，50% 透明）+ 掉落时 3 帧旋转高光 |

> 实测：在 480×270 的视口里，`#4A4468` + 外发光会被玩家稳定识别为"紫色"，不需要真正的紫色。

### 6.1.2 调色板纪律

- 单帧内不超过 **8 色**（含描边）。超过就会破坏像素风的统一感。
- 阴影不用半透明，用**同一色相的下两档**做"硬阴影"（例：正红 `#C62828` 的阴影是暗红 `#8C1C1C`，不是红色 50% 透明）。
- 渐变只在 480×270 的远景层使用，瓦片层禁用渐变。
- 亮度单调：任何元素的最亮处不超过 `#F2EDE4`，最暗处不低于 `#0D0B14`。

### 6.2.2 不打包图集，按路径直取

早期设计稿计划用 1024×1024 图集 + TexturePacker。**实际没有采用**，原因三条：

1. 素材总量只有 457 KB，打包收益为零；
2. 单帧 PNG 可以按幕懒加载——第一幕不需要第二幕的贴图；
3. 图集一改就得重打包，而本项目的美术是"甲方给一张图 → 拆帧入库"的零散节奏。

代价是首屏请求数偏多（约 60 个 PNG），但在 HTTP/2 下可接受；且这些图大多在进入关卡时才加载。

### 6.2.3 命名与规格约定

- 单位贴图：`units/<unit>_<down|left|right|up>.png`，24×32，四朝向各一帧（**没有行走/攻击动画帧**，动作用位移与翻转表现）。
- 瓦片：16×16，文件名即语义（`grass_0`、`sand_1`、`water_1`…）。
- 特效：`fx/<名字>/fx_<两位序号>.png`，帧数写进 `FX_CANNON_FRAMES`，改帧数必须同步常量与测试。
- 贴花：`scars/scar_<两位序号>.png`，按 0.5 缩放铺在地面纹理上。
- 配色：所有新图必须从 6.1 的 24 色取色。

## 6.6 音频

### 6.6.1 已实现：Web Audio 合成音效（✅）

**没有任何音频文件**。`src/systems/AudioKit.ts` 用振荡器 + 白噪声现场合成，体积 0。

| 方法 | 听感 | 用在哪 |
| --- | --- | --- |
| `cannonAftermath()` | 远处滚过的一串闷雷 | 炮台战斗开场、城破前的留白 |
| `cityFall()` | 一记重锤 + 六下碎石 | 天京陷落演出 |
| `bell(times)` | 下行丧钟，默认 3 声 | 就义、结尾 |
| `setMuted(v)` | 总闸门（master gain） | 设置里的静音 |
| `silenceBattle()` / `resumeBattle()` | 战斗层音效闸门 | 演出开始/结束时静默 |

三条实现铁律（改这个文件前必读）：**懒创建** `AudioContext`（用户手势前建会被浏览器挂起）、**任何异常都吞掉**（iOS/微信限制多，音效失败不能炸掉演出）、**一次演出只建一条 master 链**。

**禁用来源**

- 商业游戏、影视、纪录片的提取音源与图像（包括"听起来像"的仿制）。
- 来源不明的"资源包"、网盘分享、二手搬运。
- 任何要求"署名但联系不到作者"的素材。
- 使用真实历史照片、真实人物肖像（本项目全部用像素插画替代）。

### 6.6.5 音频技术规范

| 项目 | 规范 |
| --- | --- |
| 格式 | 移动端统一 MP3（兼容性最好），桌面端可加 OGG 备选 |
| 码率 | BGM 64 kbps 单声道（像素游戏不需要立体声）；SFX 48 kbps |
| 采样率 | 22.05 kHz（复古感 + 体积小） |
| 加载 | 首屏只预载 3 首 BGM + 12 条核心 SFX；其余按幕懒加载 |
| 播放 | WebAudio API；Phaser 内置 Sound Manager；`unlock` 手势在标题画面完成 |
| 音量 | SFX 默认 0.8、BGM 默认 0.6，可在设置内独立调节（存档记忆） |
| 静音场景 | 就义、悼念段落**强制关闭全部音效与 BGM**，只保留极低的环境音或完全静音 |
