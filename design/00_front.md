## v1.2 → v2.0 主要变更

| 编号 | 变更项 | 说明 |
| --- | --- | --- |
| R-01 | 序章阵营设定修订 | 原表将序章整体标记为"清王朝阵营"。本设计书改为"**旧中国·各阶级代表**"：玩家依次扮演清军将领、农民起义军、洋务将领、维新志士、革命党人，**每一次都失败，最终在五四运动中完成转向**。理由见 3.1 节。 |
| R-02 | "九一八事变"归属澄清 | 时期框架表中"九一八事变"同时出现在第三章与第四章。本设计书明确：第三章内以**时局过场 + 事件卡**处理（第三章主体为土地革命战争），第四章第一幕以**东北抗日联军游击战**为玩法主体。 |
| R-03 | 《序章》玩法形式问句作答 | 原表序章"游戏形式"栏为空并附问句"什么形式能实现关键词和事件的一一对应？"。本设计书以 **2.2 节「一事件一卡一节点」原则** + **第三章时间轴长廊结构**作答。 |
| R-04 | 第一章时间范围补齐 | 原表第一章为 1921—1923，但仅列出"中共一大建立"。本设计书补入中共二大、中共三大、京汉铁路大罢工作为**章内补充节点**（非主幕）。 |
| R-05 | 敏感史实处理原则 | 新增 1.5.4 节"内容红线"，明确南京大屠杀、文化大革命等内容的不可玩化处理规范。 |
| R-06 | 全章节玩法形式补全 | 原表第二章至第十章"游戏形式"栏仅有词组。本设计书补全为**可开发的幕结构 + 玩法原型 + 关卡流程**（第三章至第五章）。 |
| R-07 | 数值与数据结构新增 | 原 v1.2 未定义数值公式与 JSON schema。本设计书新增第六章（系统数值）与第七章（数据表设计）。 |
