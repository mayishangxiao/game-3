二、图层结构：四层编辑源 → 引擎两层

逻辑层内容落地到 MapDef碰撞
L0 地形 terrain草地 / 土路 / 稻田 / 石板 / 城墙砖 / 水 / 焦土layers[0].name = "ground"（底图）否
L1 建筑 building村舍 / 城墙 / 城门 / 箭楼 / 王府 / 铺面 / 粮仓 / 木桥覆盖 ground 同格瓦片号逐瓦片（多数阻挡）
L2 装饰 decoration松 / 竹 / 旗 / 灯笼 / 箱桶 / 沙袋 / 拒马 / 炮位 / 营帐覆盖 ground 同格瓦片号 + objects[] 布景逐瓦片（掩体阻挡）
L3 碰撞 collision边界 + 建筑 + 阻挡装饰的并集，0/1layers[1].name = "collision"是
foreground 层禁用：设计书 10 号规定它会挡住角色；远景用 sky_rows 交给 LevelScene 叠远景条。
折叠规则：ground = terrain → building 非零覆盖 → decoration 非零覆盖；collision 取各层 collidable 瓦片并集。四层原始数组保存在 public/art/tiles/tp/layers/*.layers.json，美术改完重跑生成器即可得到引擎 JSON。

命名规则：tp_<类别>_<语义>[_两位变体]，全小写 snake_case；地图 map_ch00_tp_<场景>；物件 obj_tp_<场景>_<两位序号>。id 0 恒为透明空瓦片，1..36 与 tile_colors 键一一对应，禁止复用或跳号。

八、边界与硬性约束

项值依据
瓦片 / 网格16×16 px；30 列 × 16 行 = 480×256 px，单屏不滚动constants.ts TILE / FIELD_COLS / FIELD_ROWS
坐标范围格 x=0..29, y=0..15；世界 x=0..479, y=0..255；外圈 1 格实心MapRenderer.isSolidAtWorld 越界视为实心
通道净宽≥ 2 格（32 px），推荐 3 格；角色 24×32，脚底四角采样Player.moveWithCollision / footBlocked
出生点村落 (2,8)、城池 (13,8)、战场 (3,9)，均非实心data.test.ts
远景带战场 sky_rows=4，0..3 行透明且碰撞全实心art.test.ts / HORIZON_ROWS=4
残破贴花仅战场 battle_scars=true（村道/城池不加）MapRenderer.paintScars
物件避让物件中心离虚拟按键圆心 > r + 8（pickup 再 +10）CONTROL_LAYOUT / data.test.ts
布景 payload只能取 SUNNY_PROPS 表内名字（rock / sign / skulls / spikes…）art.test.ts
