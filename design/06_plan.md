## 7.2 验收（可执行，按顺序跑）

```bash
pnpm exec tsc --noEmit          # 类型
pnpm test                       # 13 个测试文件，见 game/tests/README.md
pnpm build                      # 产物能构建
node game/tools/serve.mjs       # 起本地服务（另开一个终端）
node game/tools/cdp-e2e.mjs     # 端到端：首屏 → 第一幕 → 战斗 → 存档
```

> 端到端脚本占用 CDP 端口 9335，**同一时间只能跑一个**（`cdp-act2` 与 `cdp-dungeon` 也用它）。改动涉及 UI 时必须逐张看截图，断言全绿但按钮被摇杆压住这种事发生过。

| 编号 | 验收项 | 通过条件 | 测量方式 |
| --- | --- | --- | --- |
| A-1 | 引擎稳定 | 连续运行 20 分钟无崩溃、无卡死 | Chrome 开发者工具监听 |
| A-2 | 流程可通 | 标题 → 两幕 → 章末测验一气呵成，无需重开 | 3 名试玩者全部完成 |
| A-3 | Boss 可过 | 每个 Boss 在 40 秒内可通过（含走位与闪避） | 计时器统计 |
| A-4 | 存档可靠 | 中途退出 → 重新打开 → "继续" → 回到离开位置 | 任意关卡中途退出再恢复 |
| A-5 | 首屏速度 | 点击链接到标题画面 ≤ 3 秒（4G） | Chrome 限速 Fast 3G |
| A-6 | UI 不重叠 | 刘海、摇杆、微信地址栏都不遮挡 HUD | 3 台安卓 + 1 台 iPhone 截图 |
| A-7 | 史实准确 | 11 张事件卡、12 张知识卡经 2 人交叉校对 | 逐卡打勾（7.5） |
| A-8 | 不娱乐化敏感内容 | 按 1.5.4 的四类处理规范执行 | 逐段截屏校对 |
| A-9 | 知识留存 | 通关后做章末测验，答对 ≥ 3 题 | 真实数据（出题人本人不计） |
| A-10 | 文档与代码一致 | `pnpm test` 里的 `docs.test.ts` 全绿 | 自动 |

## 7.5 史实校对流程

经过校对的内容才是"党史游戏"，没经过校对的内容只是"同人"。这个流程必须执行。

### 7.5.1 校对层级

| 层级 | 负责 | 工具 | 产出 |
| --- | --- | --- | --- |
| L0 · 开发者自校 | 开发者本人 | 事件卡的 `five_element_check` 逐卡打勾 | 五要素自查表 |
| L1 · AI 互校 | 换用校对提示词再跑一遍 | JSON diff | 可疑条目报告 |
| L2 · 同伴交叉校对 | 另一名了解党史的同学 | JSON + 表格 | 逐卡校对签名 |
| L3 · 思政课老师审阅 | 思政课老师（自愿参与） | 可玩版本 | 最终意见 |

**交付要求**：全部事件卡与知识卡至少通过 L1 + L2。

### 7.5.2 五要素自检脚本（`lint_history.js`）

```javascript
// 伪代码：遍历所有 events_*.json 与 knowledge_*.json
// 1. date 非空，且日期格式规范
// 2. place 非空，且含具体城市或建筑名
// 3. figures 至少 1 项（无虚构名）
// 4. document 若为空则已显式标注 ""
// 5. result 20—80 字
// 6. 与 banned_phrases.json 中的禁用表述无匹配
// 不通过的条目写入 lint_report.json，CI 阻断。
```

### 7.5.3 禁用表述清单（`banned_phrases.json`）

| 类型 | 示例 | 替代 |
| --- | --- | --- |
| 网络化称谓 | "老毛""蒋光头"等 | 使用规范姓名 + 职务 |
| 娱乐化动词 | "干掉""爆头"（正式历史关卡） | "歼灭""击败" |
| 国名/民族全称泛化 | "日本人都是…" | "日本侵略者""日军" |
| 模糊日期 | "1927 年某天" | 补到月份，无法补齐则标注"时间待考" |

> 300 元代金券足够本期全部 AI 需求。

### 7.6.3 AI 使用纪律

1. **AI 产出的内容绝不直接进数据文件**。先写进 `_ai_draft/`，人工校对后搬进正式路径。
2. **对话生成**：每幕一次批量请求，Prompt 包含本幕全部事件卡的五要素 + 原型描述 + 字数约束。
3. **校对**：用独立提示词，只传 ID + 当前内容（不传生成模板），避免模型"自我确认"。
4. **预算耗尽预案**：字段结构都在第五章定死了，全部字段都有人工填写的备选方案——**可以不用 AI，只是更慢。**
