# SpriteLab 全套提示词（鸦片战争原型 P0+P1）

> 用法：每条英文直接粘贴到 sprite-lab.com 输入框。尺寸在网页上选好再生成。
> 风格尾巴固定不变（`16-bit pixel art, front view standing...`），前面换角色描述。
> 出图后挑剪影对、服饰对的，不满意就再生成。


## 出图后检查清单

每条出图后对一下：
1. **剪影对不对**——关天培有长须+圆帽，林则徐有帽翅，英军有高筒帽，绿营有尖顶斗笠
2. **颜色对不对**——英军红衣、清军绿衣/深蓝官服、船深紫灰
3. **是不是透明底**——SpriteLab会给透明PNG，如果带白底要去背景
4. **尺寸对不对**——角色32×40、Boss96×48、箱子20×20、瓦片16×16
5. **有没有多余东西**——不要文字、不要水印、不要其他人物

挑好的图存下来，接进 `game/public/art/` 对应目录，按10号7.1命名规则改名。
