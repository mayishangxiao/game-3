# 第五章 第二章至第十章逐章设计

> 本章是第二期、第三期的设计基准。每章采用统一模板：**章节定位 → 幕结构 → 差异化机关 → Boss 与挑战 → 知识卡 → 验收点**。
> 与第三章、第四章相比，本章不展开到每个交互的三分钟流程，但**每个事件卡都已完成"原型归属 + 玩法一句话"的落地**，具备直接开工条件。

### 5.1.3 差异化机关

- **"两条路线"的双线地图**：北伐沙盘上，玩家只有有限的兵力与补给，先打吴佩孚或先打孙传芳会有完全不同的战果。正确答案是历史上实际的方案——**集中兵力、各个击破，先打吴佩孚**。选错会遭受重大损失，但可以重来。
- **合作机制的数值化**：本幕维护一个隐藏的"**合作度**"数值。国民党的让步、工农运动的高涨、共产党的独立性都在加减这个值。合作度归零时，四一二必然发生——**让玩家提前看见危机的迫近，而不是突然被人背后捅刀**。
- **善用"看不见的敌人"**：四一二政变不做正面战斗（历史上这是突然的屠杀），做成**深夜潜行逃生**：玩家在工人纠察队驻地被包围后，只能沿着屋顶、后巷、下水道逃出，途中会遇到正在被搜捕的同志，每救一人会拖慢自己。**这是全游戏情绪最沉重的一幕，任何战斗胜利的爽感都不允许出现。**

### 5.2.3 差异化机关

- **"支部建在连上"的机制化**（三湾改编）：改造前，玩家的部队会出现"溃散"（士兵逃跑）；改造后，部队获得"凝聚力"（不会溃散、可重整）。玩家做的不是点一个按钮，而是**把指导员派到每个连队**——一个拖拽分配的小玩法，看得见效果。
- **五次反"围剿"的对比结构**：前四次胜利（塔防，可赢），第五次失败（**塔防中玩家的"堡垒"无法移动，而敌人有碉堡推进**，怎么打都输）。这个玩法设计本身在讲"阵地战对堡垒战"的错误。**玩法即论证。**
- **湘江战役的"不可胜"设计**：这是全作少数几个"玩家必输且不能重来"的战斗。中央红军由 8.6 万人减至 3 万余人。设计上让玩家守一个不可能守住的渡口，友军一个个倒下，最后只剩玩家一人过江。**不允许"完美通关"，也不给"失败"字样，只给"1934.12 湘江"。**
- **遵义会议的"会议还原"升级**：本幕的会议模块引入**发言顺序机制**——玩家必须按历史的实际顺序（博古报告 → 周恩来副报告 → 张闻天反报告 → 毛泽东发言 → 王稼祥、朱德等发言）安排发言。顺序错了，会议就无法达成共识。**让玩家理解"会议是怎么开的"比"结论是什么"更难也更重要。**
- **雪山草地的资源极限管理**：G 类模块的极限版——口粮、草鞋、弹药三项，每推进一天全部减 1，而地图上有随机出现的"野菜/野果/皮带"补给点。玩家必须做出"分给谁"的抉择。**设计准则：这一段不设置"完美解"，无论如何都会有人掉队。**

### 5.3.3 差异化机关

- **雪原游击的三重压力**：东北抗联幕同时施加"极寒（持续掉血）""补给（无村庄可买）""围剿（日军讨伐队定时巡逻）"三种压力。玩家的解法不是硬打，而是**转移密营**——一条有限次数的地图操作。**这是全作唯一一个"逃跑是主要玩法"的章节。**
- **百团大战的"破袭"设计**：本幕不是单纯的杀敌，而是破坏铁路、桥梁、电线杆、矿井。地图上有 12 个目标物，每破坏 1 个，敌军的"增援速度"降一档。**成就感来自"把敌人的路挖断"，而不是"把敌人打死"。**
- **机枪限定关**：百团大战中有一个固定的"炮楼攻坚"关卡，玩家在此短暂获得机枪（`wp_mg`），弹药无限但换弹 3 秒。这是全作唯一一次"火力全开"的爽感设计，刻意只给一关。
- **南京大屠杀的处理（内容红线）**：**不设可玩节点**。以静帧 + 文字 + 一分钟静默呈现，禁止任何数值、禁止击杀、禁止成就与掉落。呈现后强制触发知识卡与悼念页。技术上这一段是**独立的、不可跳过但极短的过场模块**，且不记录任何"完成度"与"得分"。
- **皖南事变的设计难点**：历史上新四军是被围歼的，且中央要求"坚决执行北上命令、不打第一枪"。玩法设计为：**玩家可以战斗，但每开一枪，关卡评价就下降一档**；真正的通关方式是"边打边撤、保存尽可能多的人"。**让玩家在"想打"和"不能打"之间挣扎，是这一幕的教育点。**
- **延安整风的思想抉择**：不是考试，而是让玩家读三份文件（改造我们的学习 / 整顿党的作风 / 反对党八股）的节选，然后对三个"主观主义/宗派主义/党八股"的现实案例做判断。判错不扣分，但会给出"当时的同志也曾这样想"的解释。
