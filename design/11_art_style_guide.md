# 美术风格指南 v0.1（Art Style Guide）

> 这份文件管"**画出来好不好看**"。
> 它和《10_art_spec_opium.md》的分工：
>
> | 文件 | 管什么 | 类比 |
> | --- | --- | --- |
> | `07_assets.md` / `10_art_spec_opium.md` | 尺寸、色号、锚点、命名、验收脚本 | 施工安全手册（不能挖多深、电线走哪） |
> | **本文件（11）** | 造型、氛围、参考、流水线、表情画法 | 建筑效果图（这楼应该长什么样） |
>
> 一句话：**10号出的东西必须过10号的验收脚本；本文件出的方向必须过11号的"好不好看"清单。** 两份冲突时，尺寸/色号以10号为准，造型/氛围以本文件为准。

---

## 0. 这份文件解决什么问题

v1 交付的102张PNG全部通过了10号的10条验收脚本，但游戏截图里角色像火柴人、立绘像方块脸。原因不是尺寸错了或色号越界了，而是：

1. 没有**参考图**——"16-bit pixel art"这个词在AI那里对应一万种风格。
2. 没有**造型规则**——只规定了头宽12px，没规定脸怎么画、帽子什么形状、影子怎么落。
3. **颜色预算过紧**——单帧8色在32×40里意味着没有余色画表情。
4. **AI被要求直接出sprite**——AI是概念画师，不是像素动画师。

本文件把这四件事补成可执行的流程。

## 1. 风格锚点（Style Anchor）

> 这是整份文件最重要的一节。**没有参考图，后面所有文字都是空话。**

### 1.1 三句话定位

在动笔之前，先用三句话说清楚"我们要的是什么"。全项目统一，不准每章换一种风格。

```
1. 角色比例：参考《星露谷物语》——约2.5头身，头占身高1/3，身体写实简化，
   不是Q版萌系大眼，也不是8位机火柴人。
2. 服装考据：清代/英军1840年代形制要准（参考10号第6节史实表），
   但用像素简化——帽子、补子、腰带要有，多余的褶皱不画。
3. 整体色调：星露谷的温暖明亮我们不照搬——鸦片战争是压抑悲壮的，
   沙黄+灰紫+深蓝为主，正红只留给英军和血，星黄只留给交互。
```

### 1.2 参考图集（已选定：《星露谷物语》截图）

> 三张参考图存在 `design/art_reference/` 目录。AI生图时把参考图喂给工具的"图生图/参考图"功能，权重0.5-0.7。文字提示词只改服装颜色和身份，**风格让参考图带**。

| 编号 | 文件 | 参考它什么 | 不参考它什么 |
| --- | --- | --- | --- |
| REF-01 | `art_reference/ref01_beach_dock.jpg` | **瓦片画法**：沙滩有细腻沙粒但不杂乱、海水横向波纹+岸线白浪边、木栈道有板缝钉头、物体下方有投影 | 它的明亮饱和色调（我们要压暗成战场感）、现代码头设施 |
| REF-02 | `art_reference/ref02_town_portrait.jpg` | **对话立绘范式**：右下角刘易斯胸像——戴帽子、有眉毛大胡子、穿衬衫领带背带，在小框里五官清晰可读；**这就是立绘该有的样子**，不是v1的方块脸 | 欧美人面孔、现代服饰、美式乡村审美 |
| REF-03 | `art_reference/ref03_town_crowd.jpg` | **群像辨识度**：一堆NPC站在一起，每个都靠头发颜色+服装颜色+帽子形状区分，不靠脸。我们7个兵种并排时就要这个效果 | 现代休闲装、欧美发型 |

**关键结论（从参考图读出来的）**：
- 立绘走**精细像素胸像**路线（不是水墨）——星露谷证明小尺寸胸像只要画了帽子/胡子/眉毛就有表情。
- 角色描边不是纯黑1px硬边，是**深褐/深紫的细描边**，在24色盘里对应深墨#0D0B14和深紫灰#2F2B45。
- 瓦片要有**纹理变化**（沙粒、板缝、草叶），不能是v1那种纯色块。

### 1.3 反例集（"绝对不要做成这样"）

| 反例 | 为什么不行 |
| --- | --- |
| 8位机火柴人（头=两个黑点、身=一个方块） | 我们是16位，要有表情和体积 |
| 萌系大眼/Q版 Chibi | 鸦片战争是悲壮题材，不是治愈游戏 |
| 3D渲染后转像素（有柔和阴影、抗锯齿） | 我们要硬边、1px描边、无渐变 |
| 米字旗画成丹麦国旗（红底白十字） | 史实错误——用24色里的深靛#1B3A6B补蓝 |
| 清军穿黄马褂 | 史实错误，见10号6.2节 |

## 2. 造型系统（Character Construction Kit）

### 2.1 比例模板（32×40画布，参考星露谷2.5头身）

```
行 1-4   顶部留白（帽缨/斗笠尖/举起的手）
行 5-14  头部（10px高，头宽10-12px）——脸在里面，头是圆形不是方块
行 15-16 脖子（2px）
行 17-26 躯干（10px）——衣服、腰带、补子
行 27-36 腿（10px）——腿占三分之一，不是火柴棍
行 37-39 鞋/衣摆（3px）
行 40    脚底线（最深色像素压这行）
```

> **v1教训**：之前按二头身画，头8px+身体13px+腿8px，腿太短像浮在空中。星露谷的腿占身高1/3，站在地上才稳。

**脸的位置**（头部在行5-14，居中）：
- 眼睛：行9-10，列13和列19，**每只眼1×2竖像素**（不是一个点，竖排两像素才有眼神）
- 嘴：行12，列15-17，1px高
- 鼻子：**不画**（32×40里画鼻子会变成污渍）
- 眉毛：行8，列13-14和列18-19，1px高（有关天培/林则徐/郭富有眉，普通杂兵可以不画）
- 胡子（关天培/林则徐）：行12-13，列14-18，2-3px灰色块贴在下唇下方

### 2.2 剪影表（最重要的辨识度规则）

> 在480×270屏幕上，玩家0.1秒看到的是**轮廓**，不是衣服颜色。每个角色必须有一个"一眼认出"的顶部剪影。

| 角色 | 头顶剪影特征 | 体型 | 武器剪影 |
| --- | --- | --- | --- |
| 关天培（玩家） | 暖帽+红顶缨（头顶一个红点），有胡子（脸下方2-3px灰色三角） | 壮（肩宽14px） | 腰刀（身侧一个弧线） |
| 林则徐 | 官帽+帽翅（头顶左右各伸出1横） | 中（肩宽12px） | 无（手持奏折=胸前一个方块） |
| 英军步兵 | shako高筒帽（头顶竖线4px高） | 中 | 滑膛枪（身侧竖长杆+刺刀尖） |
| 英军掷弹兵 | 熊皮帽（头顶黑色方块，比shako宽） | 中壮 | 同步兵 |
| 郭富准将 | 双角帽bicorne（头顶左右两个角） | 中 | 指挥刀（举起时手过头顶） |
| 清军绿营 | 尖顶斗笠（头顶一个三角形） | 瘦（肩宽10px） | 长矛（竖长杆，比人高） |
| 清军把总 | 斗笠+红缨（斗笠顶有红点） | 中 | 腰刀 |
| 蒸汽炮舰（Boss） | 三个桅杆+一个烟囱（头顶四根竖杆，中间那根最粗最黑） | 长条（96×48） | 炮门=船侧一排黑方块 |

**验收方法**：把所有角色缩到实际游戏尺寸（32×40）并排摆，盖住颜色只看轮廓——如果分不清谁是谁，打回重画。

### 2.3 表情库（在像素点上怎么画情绪）

| 表情 | 眼睛怎么画 | 嘴怎么画 | 用在哪 |
| --- | --- | --- | --- |
| 平静(idle) | 行9-10两个1×2竖点 | 行11一条1px横线 | 默认站立 |
| 严肃 | 眉毛斜下（行8列13-14往中间斜） | 嘴更短（只1px） | 对话、战斗待机 |
| 怒 | 眉毛倒八字（行8列13-14往外斜） | 嘴向下弯（行11-12中间凹） | 攻击前摇 |
| 悲/疲惫 | 眼睛变成两个向下的弧线（行9列13-14和列18-19） | 嘴向下 | 关天培阵亡前、林则徐禁烟 |
| 惊/受击 | 眼睛变成两个白点（纸白#F2EDE4） | 嘴张开=1×2方块 | hurt帧 |
| 死 | 眼睛变成两个×（行9列13+14，列19+18交叉） | 不画 | death帧 |

> **v1的问题**：所有角色都是"两个黑点+一条横线嘴"，关天培和英军步兵表情一模一样。上面这张表是补这个的。

### 2.4 服装层次与配色槽

一个角色的衣服分四层，每层从24色盘里取固定槽位：

| 层次 | 位置 | 取色规则 | 关天培示例 |
| --- | --- | --- | --- |
| 外层主色 | 躯干行16-28 | 角色识别色（10号6节史实表） | 深靛#1B3A6B（官服蓝） |
| 外层暗部 | 躯干右侧2-3列 | 主色的下一档同色相 | 深紫灰#2F2B45 |
| 内层/补子 | 胸前正中4×4方块 | 对比色 | 纸白#F2EDE4底+深靛字 |
| 配饰 | 腰带/帽/肩 | 从盘里单独取 | 深褐#7A4F2A腰带 |
| 裤子 | 行29-36 | 深色（和外层拉开） | 深紫灰#2F2B45 |
| 皮肤 | 脸行9-11 | 米黄#E8CFA8 | 米黄#E8CFA8 |
| 描边 | 全身外缘1px | 深墨#0D0B14 | 深墨#0D0B14 |

## 3. 调色板的"使用规则"

> 色号表在 `07_assets.md` 8.1节和10号第5节。这里只讲**怎么用**。

### 3.1 24色的功能分组

| 功能组 | 色号 | 用途 |
| --- | --- | --- |
| 角色主色 | 正红#C62828、军绿#2F8F5B、深靛#1B3A6B、中蓝#2F6BA8 | 每个角色只占一个主色 |
| 皮肤 | 米黄#E8CFA8 | 全项目统一，不准画别的肤色 |
| 环境/地面 | 沙黄#CFA26A、褐#A8763F、深褐#7A4F2A、浅紫灰#6B6489 | 沙滩/土墙/石板 |
| 金属/武器 | 灰紫#948DAB、中紫灰#4A4468 | 刀枪炮管 |
| 光/火 | 纸白#F2EDE4、亮红#E85C4A、浅红#F2A08C | 高光/火焰 |
| 描边/最深影 | 深墨#0D0B14、暗夜#1C1A2B | 外描边、暗部 |
| **交互专用** | 星黄#F0C419 | **美术素材绝对不准用**（10号4.2节） |

### 3.2 单角色配色预算（修订10号的8色）

10号规定"单帧≤8色"。实测在32×40画8色角色时，面部和衣服细节全挤没了。**建议放宽到12色**，分配如下：

| 用途 | 色数 | 例子（英军步兵） |
| --- | --- | --- |
| 外描边 | 1 | 深墨#0D0B14 |
| 皮肤 | 1 | 米黄#E8CFA8 |
| 上衣主色 | 1 | 正红#C62828 |
| 上衣暗部 | 1 | 暗红#8C1C1C |
| 裤子 | 1 | 深紫灰#2F2B45 |
| 帽子 | 1 | 深褐#7A4F2A |
| 帽子羽饰 | 1 | 纸白#F2EDE4 |
| 皮带 | 1 | 纸白#F2EDE4（和羽饰共用） |
| 武器 | 2 | 灰紫#948DAB + 深墨#0D0B14 |
| 眼睛/眉 | 1 | 深墨#0D0B14（和描边共用） |
| **合计实际用色** | **8-10色** | |

> 放宽到12色是"允许用12色"，不是"必须用12色"。英军步兵实际只用到8色。**关天培因为有补子和胡子，需要10色。** 10号的验收脚本需要同步把阈值从8改成12。

### 3.3 阴影与高光规则

- **阴影不用半透明**，用同色相下一档（正红的阴影是暗红，不是红50%透明）。
- **光源左上**：每个物件的右侧2-3列、下侧1-2行画暗部。全项目统一，不准一张图一个光。
- **高光只出现在左上棱线**：帽子顶、肩线、武器上缘。**不准全身撒高光**。
- **瓦片层禁用渐变**（10号5节）。角色衣服可以有2档明暗，但不准3档渐变。

## 4. 资产流水线（Pipeline）

> 这是"工业化"的核心。不管谁画、用什么工具，都走这固定的6步。每一步有明确的产出物和验收点。

### 4.1 角色精灵流水线（P0单位）

```
步骤1：填配置卡 ──→ 步骤2：AI出概念图 ──→ 步骤3：Aseprite像素化
                                                      │
步骤6：入库 ≤── 步骤5：跑验收脚本 ≤── 步骤4：画8帧动画
```

| 步骤 | 做什么 | 用什么工具 | 产出物 | 验收点 |
| --- | --- | --- | --- | --- |
| 1.填配置卡 | 按5节模板填角色身份/剪影/配色 | 本文件第5节 | 一张填好的Recipe Card | 团队确认剪影辨识度 |
| 2.AI概念图 | 喂参考图(REF-01~04)，出256×256正面站立大图，透明底 | Midjourney/即梦/SD | 1张PNG（256×256） | 剪影对不对、服装对不对、风格像不像参考图 |
| 3.像素化 | 在Aseprite里新建32×40画布，照着概念图逐像素描 | Aseprite | 1张32×40正面idle帧 | 比例符合2.1节、脸符合2.3节、配色符合2.4节 |
| 4.画8帧 | 在idle基础上画walk0/walk1/attack0/attack1/hurt/death | Aseprite | 8张32×40 PNG | 脚底线都在第40行、hurt/death符合2.3表情表 |
| 5.跑验收 | 把8帧丢进验收脚本 | `_art_review/v1/_tools/check_spec.py`（需改阈值到12色） | `acceptance_report.txt` | 10号10条全过 + 11号第6节5条全过 |
| 6.入库 | 按10号7.1命名规范存到`game/public/art/` | — | 8张PNG + 1张sheet | 代码里能加载、游戏截图里能看到 |

**时间预估**：一个新角色从配置到入库，熟手2-3小时，新手半天。

### 4.2 对话立绘流水线（精细像素胸像，参考星露谷REF-02）

> **路线修正**：原计划立绘走水墨风。看了REF-02（星露谷刘易斯胸像）后改走**精细像素胸像**——星露谷证明了96×112的小框里，像素胸像只要画了帽子/胡子/眉毛就有表情，不需要水墨。水墨和战场像素风反差太大，不统一。

| 步骤 | 做什么 | 说明 |
| --- | --- | --- |
| 1.定气质 | 这个角色是"威严/疲惫/冷静/傲慢"？写一句话 | 例：关天培="知道打不赢仍去死的悲怆" |
| 2.参考REF-02 | 打开`art_reference/ref02_town_portrait.jpg`，看刘易斯的帽子/胡子/眉毛/衬衫怎么画 | 这是立绘的风格基准 |
| 3.AI出胸像 | 喂REF-02当参考图，出512×600胸像，正面或微侧，透明底 | 提示词写"pixel art bust portrait, reference style of Stardew Valley dialogue portrait, detailed facial features, hat, eyebrows, visible expression" |
| 4.人工修脸 | AI出的脸往往不对，手动补眉毛/胡子/帽子——参考2.3表情表 | 关键：眼睛要画出情绪，不能是两个黑点 |
| 5.缩到96×112 | 最近邻缩，不要平滑 | 透明底 |
| 6.入库 | `game/public/art/portrait_<id>.png` | 在config.json的ui.portraits注册 |

**立绘必须有的东西**（对照REF-02刘易斯）：
- 帽子（每个角色的帽子是最大识别特征——暖帽/斗笠/三角帽/shako）
- 眉毛（1-2px深墨线）
- 眼睛（1×2竖像素，不是一个点）
- 嘴（根据表情画横线/下弯/张开）
- 胡子（关天培灰白、林则徐短须、郭富络腮胡）
- 衣领/肩章（服装的第一层，不要画到全身）

**v1立绘为什么丑**：关天培和林则徐都是"蓝方块身体+脸上两条横线眼睛+一条弧线嘴"。没有帽子细节、没有眉毛、没有胡子——参考REF-02刘易斯，人家有帽子、粗眉、大胡子、衬衫领带背带，信息密度完全不同。

### 4.3 瓦片流水线

| 步骤 | 做什么 | 验收点 |
| --- | --- | --- |
| 1.画单块16×16 | 在Aseprite里画，参考REF-02的色调 | 颜色从24色盘取、无渐变 |
| 2.拼3×3平铺 | 同一块复制成3×3矩阵，看接缝 | 看不出接缝（10号第7条） |
| 3.变体 | 同一种地面画3-4个变体（沙滩底/沙面点缀/过渡边） | 变体之间能混拼不突兀 |
| 4.跑验收 | `check_spec.py` | 无孤立1px亮点（10号第8条） |

### 4.4 Boss流水线

Boss（蒸汽炮舰96×48）走角色流水线，但额外注意：
- 吃水线固定在第40行（10号2.4节）
- 烟的画法：不要画成"一串黑珠"（v1踩过的坑），画成实心烟团+左上棱线提亮
- 旗帜：**不要画丹麦国旗**。用#C62828红底+#F2EDE4米字（红+白十字交叉，蓝用#1B3A6B）

### 4.5 每步失败了怎么办

| 失败点 | 处理 |
| --- | --- |
| AI概念图画得不像参考图 | 检查参考图权重是否调到0.5+；换一张参考图；文字提示词不要堆形容词 |
| 像素化后脸不好看 | 回到2.3表情表，检查眼睛是不是1×2竖点、嘴是不是在正确行 |
| 8帧动画角色会上下跳 | 检查脚底线是否都在第40行（10号第5条，脚本会查） |
| 游戏截图里角色看不清 | 缩到480×270实际尺寸看，不要看8倍放大图（10号第10节踩过的坑） |

## 5. 角色配置卡（Recipe Card）

> **加新角色时，填这张卡就行。** 不需要重写流程，不需要重写提示词。


## 6. 验收标准（在10号10条之外）

10号的脚本验收管"对不对"。下面5条管"好不好看"，需要人工在480×270实际截图里看：

| # | 检查项 | 怎么判 |
| --- | --- | --- |
| S1 | 剪影辨识度 | 所有角色缩到32×40并排，盖住颜色能分出来谁是谁 |
| S2 | 表情可读 | idle帧的脸在480×270截图里能看出"这个人有情绪"，不是两个黑点 |
| S3 | 风格统一 | 本批所有角色放在一张截图里，笔触/描边粗细/色调像同一套 |
| S4 | 参考图对齐 | 和REF-01~04比，比例/色调/描边在同一方向（不需要一模一样） |
| S5 | 真机比例不糊 | 在`qa/mock_480x270.png`实际分辨率下看，不是在8倍预览图里看 |
