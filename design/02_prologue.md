# 第三章 序章·觉醒年代（1840—1864）详细设计

> **本章就是本期要做的全部内容。** 交付两幕——第一幕·鸦片战争（地主阶级抵抗派）、第二幕·太平天国运动（农民阶级）。原设计里 1861 年之后的第三幕洋务运动、第四幕戊戌变法、第五幕辛亥革命、第六幕新文化运动、第七幕五四运动**不在本期范围，相关小节已删除**。本章文字与游戏数据（章 ID `ch00`）严格对应：两幕之外不描述、不承诺。

> 序章是本期的教学层与情绪起点。它必须在两幕之内教会玩家全部基础操作，同时让玩家明白一件事：**在共产党出现之前，中国人的每一次抗争都失败了**——这两幕是这句话的头两个证据。

## 3.1 章节概述与阵营修订（R-01）

### 3.1.1 设计问题

时期框架表把序章的阵营标为"清王朝阵营"，主角链为"关天培 → 林则徐 → 邓世昌……"。这在游戏性上通顺，但会撞上两个史实与立场问题：

1. **太平天国运动是农民阶级反抗封建统治与外国侵略的正义斗争。** 如果整章都让玩家站在清王朝一方，第二幕"太平天国运动"就会变成"玩家帮清廷镇压起义"——这与党史对太平天国的评价相冲突。
2. **序章的历史意义是"旧中国各阶级都试过了，都失败了"。** 完整设计里，地主阶级（抵抗派与洋务派）、农民阶级、资产阶级维新派、资产阶级革命派依次登场、依次失败，最终只有无产阶级领导才能救中国。本期只做到前两个阶级，但这条"失败的链条"必须在文本与界面里埋下——最终只有无产阶级领导才能救中国，这才是序章要传达的核心结论。用单一"清王朝阵营"无法承载这个结论。

### 3.1.2 修订方案

序章阵营修订为 **"旧中国·各阶级代表"**，玩家在每一幕中扮演一个阶级的代表人物，每一次努力都失败，每一次失败都以主角的牺牲或退场收束。本期只交付前两幕：

| 幕 | 化身 | 阶级/派别代表 | 结局 |
| --- | --- | --- | --- |
| 1 鸦片战争 | 关天培（广东水师提督） | 地主阶级抵抗派 | 1841 年虎门之战壮烈殉国 |
| 2 太平天国运动 | 李秀成（太平天国忠王） | 农民阶级 | 1864 年天京陷落被俘就义 |

> **设计表述**：章节载入画面固定显示一行小字——"**旧中国已经试过两次了。**"第一幕结束显示"第一次失败：地主阶级抵抗派"，第二幕结束显示"第二次失败：农民阶级"。原稿里"七次失败 → 第七次转向"的完整表达属于被删除的第 3—7 幕，**本期任何界面文案都不得出现"第七次"这类字样**。

> **为什么停在第二幕**：地主阶级抵抗派（鸦片战争）与农民阶级（太平天国）都把各自的路走到了尽头，而且是在同一片土地上失败；这一段能自成一体，也足够让玩家自己问出"那接下来该谁上？"——这个问题留给后续期次，本章不回答。

## 3.2 时间轴长廊（章节地图）

序章不使用传统的"关卡列表菜单"，而是用一张**可走动的横向时间轴长廊**。这张地图同时承担三个功能：关卡入口、进度可视化、知识点复习。

### 3.2.1 结构

```
[1840]══╤══[1851]══╤══[1864]
        幕1        幕2
      鸦片战争   太平天国
```

- 长廊总长约 12 屏宽（每屏 30 瓦片），玩家用虚拟摇杆左右行走。
- 每隔一段出现一根**年代石柱**（`16×48 px`），柱上刻年份（1840 / 1851），走近弹出提示。
- 每一幕在长廊上表现为一道**节点门**（`16×32 px`，未解锁为灰暗、已通关为点亮、已收集为镶金边）。
- 长廊两侧有**史料陈列栏**，点击可复习已收集的知识卡（相当于移动版图鉴入口）。
- 长廊尽头是一段断路，立着一块无字碑（`1864`）——本期到这里为止，后续期次从这里接上。**不要做成"1921 铁门"**，那属于被删除的第七幕。

### 3.2.2 长廊上的三个副本入口

- 幕1 之后，长廊右侧出现一个向下的岔路楼梯 → **副本·租界暗巷**（`dg01_alley`）
- 幕2 之后，长廊左侧出现一个楼梯 → **副本·广州城外匪寨**（`dg02_bandit`）
- 幕2 之后，长廊更深处再出现一个楼梯 → **副本·沪上码头**（`dg03_dock`）
- 副本入口在长廊上是永久的、可重复进入的，用小旗标记。三个副本的解锁条件见 3.4，与游戏数据 `dungeons.json` 一致。

### 3.2.3 美术需求（长廊）

| 资源 | 规格 | 数量 |
| --- | --- | --- |
| 长廊地面瓦片（青石、铁轨、荒草、泥地） | 16×16 | 6 种 |
| 年代石柱 | 16×48 | 2 个（1840/1851） |
| 节点门（三态） | 16×32 | 2×3 = 6 帧 |
| 陈列栏 | 32×32 | 2 帧 |
| 岔路楼梯 | 32×32 | 1 种 |
| 远景视差层（破碎山河→残阳） | 480×270，2 层 | 2 张 |

> **有趣的设计点**：长廊的远景视差层随进度变化。第一幕期间是阴沉的破碎山河；第二幕天京陷落之后，远景天空变成一片低沉的残阳——不是"天亮了"，而是"天黑了"。**玩家的"进度"直接变成"天色"。**（原设计中"第六幕晨光、第七幕天亮"的变化属于被删除的后续幕，不要实现。）

#### 化身与地图

- **化身**：`av_guan_tianpei` 关天培（广东水师提督）。特性：防御 +20%，攻击 -10%，体现"守而不攻"。
- **地图**：`map_ch00_act1a` 虎门海滩（白天，30×16 瓦片）；`map_ch00_act1b` 虎门威远炮台（雨夜，30×16）。

#### 玩法与关卡流程

**本幕是全游戏的教学幕，所有基础操作在此教完。**

**场景 A：虎门海滩（F 探索收集，约 4 分钟）**

1. 玩家在海滩醒来，屏幕下方出现半透明摇杆提示。走动 3 秒后提示消失（教学模式：做出来即消失，不用"确定"按钮）。
2. 走近第一个鸦片箱，出现"交互"按钮 → 按一下，角色扛起箱子。
3. 走近销烟池，交互 → 箱子倒入池中，池水冒泡、白烟升起（粒子特效），屏幕右上角计数 `鸦片 1/8`。
4. 重复 8 次，中间穿插 2 段林则徐 NPC 对话（`np_linzexu_pool1/2`），说明销烟的规模与意义。
5. 第 8 箱投入后，林则徐走近，触发最后一句话："**若鸦片一日未绝，本大臣一日不回。**" → 知识卡入袋。
6. 教学插片 Q：1 题选择题（虎门销烟发生在哪一年？）——教玩家"知识卡和测验长什么样"。

**场景 B：虎门威远炮台（C 即时战斗，约 6 分钟）**

1. 教学插片：武器切换。玩家默认持刀（`wp_dao`），按攻击键挥砍木桩，木桩破碎（打击感三件套首次登场：命中闪白 + 击退 + 像素碎屑）。
2. 教学插片：闪避。敌舰第一轮炮击落下（地面出现红圈预警），玩家必须翻滚躲开，否则掉血。
3. 教学插片：拾取与装备。击退第一批登陆英兵后掉落一把白色的弓（`wp_bow`），走近自动拾取，弹出装备提示，攻击方式变为远程。
4. **波次结构（共 3 波 + Boss）**
   - 波次 1：英军步兵 ×4（近战登陆兵，直线冲锋）
   - 波次 2：英军步兵 ×5 + 掷弹兵 ×2（远程抛物线）
   - 波次 3：英军军官 ×1（精英，带护盾，需闪避他的一次突刺）+ 步兵 ×4
   - **Boss：英军蒸汽炮舰（`en_boss_steamfrigate`）** — 停在炮台外侧海面，血条分两段。攻击方式：① 舷炮齐射（扇形弹幕，需躲到垛口后）② 投放登陆艇（召唤 2 名步兵）③ 舰首撞角冲滩（一次直线冲刺，躲开后炮舰卡在浅滩，露出弱点 8 秒）。
5. 血量降到 30% 时触发剧情：**弹药耗尽**。屏幕提示"炮弹已尽"，玩家只剩刀与弓。此时关天培触发独白，随后进入固定结局。
6. **历史性收束**：Boss 不会被击杀。最后一击由玩家打出后，炮舰退去，炮台已是残垣——关天培身中数创，画面静音、变灰，出现"1841.2.26 虎门"字样。**主角阵亡，自动切换到下一幕化身。**

#### 化身与地图

- **化身**：`av_lixiucheng` 李秀成（太平天国忠王）。特性：周围 3 格内友军攻击 +15%（"带兵"）。
- **地图**：`map_ch00_act2a` 金田村山地（清晨，30×16）；`map_ch00_act2b` 天京城（城墙 + 街市 + 王府，30×16）；`map_ch00_act2c` 天京城墙（夜战，30×16）。

#### 玩法与关卡流程

**场景 A：金田突围（C，约 5 分钟）**

- 玩家带 3 名太平军战士（可控 AI 友军），从村口向外突围。
- 波次：清军绿营（慢、血低、数量多）→ 清军骑兵（快、冲锋，需闪避）→ 清军把总（精英）。
- 目标不是"杀光"，而是**把 3 名友军带到地图右端**（保护目标）。这是本作第一次出现"护送"目标，教玩家"战友"的存在。
- 到达终点触发：洪秀全宣布起义，旗号"太平天国"升起。

**场景 B：天京经营（G 建设经营，约 6 分钟）**

这是全作第一个非战斗的轻度经营模块，机制刻意做得简单但**主题明确：资源永远不够**。

- 界面：三根分配条（粮草 / 兵员 / 民心），每月每个条需要分配点数，总点数固定为 6 点/月。
- 推进 8 个月，每月结算：
  - 粮草 < 2：兵员下降
  - 兵员 < 2：城墙脆弱度上升
  - 民心 < 2：出现逃亡事件，粮草与兵员同时下降
  - 三项都 ≥ 2：进入"盛世"，出现正面事件
- **设计要点**：总点数 6 点，恰好**无法**让三项长期都 ≥ 2。玩家必然要牺牲一项。这就是"农民阶级的局限性"——**不是不努力，是没有能力建立科学的社会制度。** 玩家会亲身感到"怎么分都不够"。
- 结束时给出评价：无论玩家怎么分，结算文案都是"天京的粮仓渐渐空了"。

**场景 C：天京守城（C 即时战斗，约 7 分钟）**

- 玩法：塔防式即时战斗混合——玩家在城墙上移动，操作两门城防炮（限时冷却），同时下城与攻入城内的敌军近战。
- 波次 4 波 + Boss。
- 第 4 波后城墙被轰开一个缺口，敌军涌入。
- **Boss：湘军 + 洋枪队联合部队（`en_boss_xiangarmy`）** — 表现为一名湘军统领（近战大刀，重甲）+ 洋枪队队长（远程火枪，伤害高但装填慢）。两人同场，需分而治之。
- 结局：城破后进入固定过场，李秀成被俘、就义；太平天国运动失败。

#### 敌人与 Boss

## 3.4 序章副本（3 个）

副本与剧情解耦，纯粹为战斗与刷装备服务。设计目标：单次 3—5 分钟，可重复，掉落随难度提升。三个副本的 ID、解锁幕、波次与掉落与 `game/public/data/dungeons/dungeons.json` 一一对应——**改设计必须同步改 JSON**。

### 3.4.1 副本 · 租界暗巷（`dg01_alley`）

| 项目 | 内容 |
| --- | --- |
| 解锁 | 通关第一幕；推荐等级 Lv3 |
| 地图 | 窄巷（`map_dg01_alley`，宽度是常规地图的一半） |
| 玩法 | C 即时战斗，3 波 + 精英 |
| 敌人 | 巡捕 ×3 → 巡捕 ×2 + 流氓打手 ×3 → 流氓打手 ×2 + 包打听精英 ×1 |
| 特殊机制 | **竹尖坑陷阱**（踩中掉血并减速 2 秒）、**铜锣诱敌**（打击铜锣把远处敌人引到陷阱区） |
| 掉落权重 | 白 45% / 蓝 40% / 紫 15% |
| 独特掉落 | `eq_acc_concession_blue_01` 蓝色饰品"租界通行证"（+移速） |

> 窄巷设计的用意：**把玩家的注意力从"跑位"转向"利用地形"**。竹尖坑与铜锣诱敌来自旧 Godot 项目已验证的设计，直接复用。

## 3.5 序章数值配置

| 项目 | 数值 |
| --- | --- |
| 玩家起始等级 | Lv1（HP 100 / ATK 10 / DEF 4 / 移速 72 px/s） |
| 序章结束预期等级 | Lv5—8（两幕打完的基础经验约 800，击杀经验另计） |
| 敌人等级带 | 普通 1—3 级，精英 3—4 级，Boss 4—6 级 |
| 单幕基础经验（通关结算） | 320（第一幕） / 480（第二幕） |
| 击杀经验 | 杂兵 6 / 标准兵 10 / 远程兵 12 / 精英 45 / Boss 200（每杀一个结算一次） |
| 首通必给 | 第一幕 `eq_wp_bow_white_01` 白色弓；第二幕 `eq_leg_taiping_blue_01` 蓝色腿部 |
| 紫色装备 | 两幕本身不保底紫装，紫装由副本产出（见 3.4） |
| 玩家在序章可解锁武器 | 刀（初始）、弓（第一幕） |
| 序章教学覆盖 | 移动、交互、拾取、装备、近战、远程、闪避、护送、经营、抉择、知识问答 |

> **数值意图**：序章的难度曲线刻意"偏软"。史实上这两次都是失败，游戏里不应让玩家在操作上再受一次挫——**让玩家"赢下每一场战斗，却输掉整段历史"**，这个反差才是序章的情绪设计。基础经验 800 + 击杀经验刚好把玩家送到 Lv5—8，既不"练废"也不"越级"。
