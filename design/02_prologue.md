# 第三章 序章·觉醒年代（1840—1912）详细设计

> **本章就是本期要做的全部内容。** 交付五幕——第一幕·鸦片战争（地主阶级抵抗派）、第二幕·太平天国运动（农民阶级）、第三幕·洋务运动（地主阶级洋务派）、第四幕·戊戌变法（资产阶级维新派）、第五幕·辛亥革命（资产阶级革命派）。原设计里的第六幕新文化运动、第七幕五四运动**不在本期范围**，1921 年之后的内容属于第二章。本章文字与游戏数据（章 ID `ch00`）严格对应：五幕之外不描述、不承诺。

> **收卷条件（唯一）**：全篇只在清王朝覆灭（1912 年 2 月 12 日宣统帝退位）时结束。前面四幕无论多惨，都只是"又一次失败"，界面文案不许出现"到此收卷 / 游戏结束"这类字样——这条由 `game/tests/chronicle.test.ts` 直接断言。

> 序章是本期的教学层与情绪起点。它必须在五幕之内教会玩家全部基础操作，同时让玩家明白一件事：**在共产党出现之前，中国人的每一次抗争都失败了**——这五幕就是这句话的五个证据。

## 3.1 章节概述与阵营修订（R-01）

### 3.1.1 设计问题

时期框架表把序章的阵营标为"清王朝阵营"，主角链为"关天培 → 林则徐 → 邓世昌……"。这在游戏性上通顺，但会撞上两个史实与立场问题：

1. **太平天国运动是农民阶级反抗封建统治与外国侵略的正义斗争。** 如果整章都让玩家站在清王朝一方，第二幕"太平天国运动"就会变成"玩家帮清廷镇压起义"——这与党史对太平天国的评价相冲突。
2. **序章的历史意义是"旧中国各阶级都试过了，都失败了"。** 地主阶级（抵抗派与洋务派）、农民阶级、资产阶级维新派、资产阶级革命派依次登场、依次失败，最终只有无产阶级领导才能救中国。五幕正好把这条"失败的链条"走完一遍——这才是序章要传达的核心结论。用单一"清王朝阵营"无法承载这个结论。

### 3.1.2 修订方案

序章阵营修订为 **"旧中国·各阶级代表"**，玩家在每一幕中扮演一个阶级的代表人物，每一次努力都失败，每一次失败都以主角的牺牲或退场收束。本期交付五幕：

| 幕 | 化身 | 阶级/派别代表 | 结局 | 国运收在 |
| --- | --- | --- | --- | --- |
| 1 鸦片战争 | 关天培（广东水师提督） | 地主阶级抵抗派 | 1841 年虎门之战壮烈殉国 | 70 |
| 2 太平天国运动 | 李秀成（太平天国忠王） | 农民阶级 | 1864 年天京陷落被俘就义 | 55 |
| 3 洋务运动 | 李鸿章（直隶总督·北洋大臣） | 地主阶级洋务派 | 1895 年甲午战败、《马关条约》签订 | 35 |
| 4 戊戌变法 | 康有为（工部主事·维新派领袖） | 资产阶级维新派 | 1898 年戊戌政变，变法 103 天而终 | 25 |
| 5 辛亥革命 | 孙中山（同盟会总理·临时大总统） | 资产阶级革命派 | 1912 年清帝退位，帝制终结、果实被窃 | 0 |

> **设计表述**：章节载入画面固定显示一行小字——"**旧中国已经试过五次了。**"每一幕结束显示"第 N 次失败：<阶级>"。原稿里"七次失败 → 第七次转向"的完整表达属于不在本期的第六、七幕，**本期任何界面文案都不得出现"第七次"这类字样**。

> **为什么停在第五幕**：清王朝覆灭是"旧中国各阶级都试过了"这条链的终点——帝制结束，但半殖民地半封建的社会性质没有改变，革命果实被袁世凯窃取。这个"结束但不是胜利"的落点，正好把问题交给后续期次："那接下来该谁上？"本章不回答。

## 3.2 时间轴长廊（章节地图）

序章不使用传统的"关卡列表菜单"，而是用一张**可走动的横向时间轴长廊**。这张地图同时承担三个功能：关卡入口、进度可视化、知识点复习。

### 3.2.1 结构

```
[1840]══╤══[1851]══╤══[1861]══╤══[1898]══╤══[1911]══[1912]
        幕1        幕2        幕3        幕4        幕5      终局
      鸦片战争   太平天国    洋务运动   戊戌变法   辛亥革命   帝制终结
```

- 长廊总长约 12 屏宽（每屏 30 瓦片），玩家用虚拟摇杆左右行走（当前实现为横向滚动，见 D-1）。
- 每隔一段出现一根**年代石柱**（`16×48 px`），柱上刻年份（1840 / 1851 / 1861 / 1898 / 1911），走近弹出提示。
- 每一幕在长廊上表现为一道**节点门**（`16×32 px`，未解锁为灰暗、已通关为点亮、已收集为镶金边），共 5 道。
- **长廊顶部常驻一条国运血条**（"清王朝 100"），底部提示"通关本幕后　国运 → N"。进一幕掉一截：70 / 55 / 35 / 25 / 0。
- 长廊两侧有**史料陈列栏**，点击可复习已收集的知识卡（相当于移动版图鉴入口）。
- 长廊尽头是第五幕之后的一段断路，立着一块刻 `1912` 的碑——走到这里、国运归零，才进终局卡「清 王 朝 覆 灭」。**不要做成"1921 铁门"**，那属于不在本期的第七幕。

### 3.2.2 长廊上的三个副本入口

- 幕1 之后，长廊右侧出现一个向下的岔路楼梯 → **副本·租界暗巷**（`dg01_alley`）
- 幕2 之后，长廊左侧出现一个楼梯 → **副本·广州城外匪寨**（`dg02_bandit`）
- 幕2 之后，长廊更深处再出现一个楼梯 → **副本·沪上码头**（`dg03_dock`）
- 副本入口在长廊上是永久的、可重复进入的，用小旗标记。三个副本的解锁条件见 3.4，与游戏数据 `dungeons.json` 一致。

| 资源 | 规格 | 数量 |
| --- | --- | --- |

| 年代石柱 | 16×48 | 5 个（1840/1851/1861/1898/1911） |
| 节点门（三态） | 16×32 | 5×3 = 15 帧 |

> **有趣的设计点**：长廊的远景视差层随进度变化。第一幕期间是阴沉的破碎山河；第二幕天京陷落之后，远景天空变成一片低沉的残阳；第三幕江南的烟囱把天压成铅灰；第四幕戊戌政变之夜整片天是暗红；第五幕武昌枪响后天边透出一线光，但**不是大亮**——帝制终结了，路还长。（原设计中"第六幕晨光、第七幕天亮"的变化属于不在本期的后续幕，不要实现。）

#### 化身与地图

- **化身**：`av_guan_tianpei` 关天培（广东水师提督）。特性：防御 +20%，攻击 -10%，体现"守而不攻"。
- **地图**：`map_ch00_act1a` 虎门海滩（白天，30×16 瓦片）；`map_ch00_act1b` 虎门威远炮台（雨夜，30×16）。

#### 玩法与关卡流程

**本幕是全游戏的教学幕，所有基础操作在此教完。**

**场景 A：虎门海滩（F 探索收集，约 4 分钟）**

1. 玩家在海滩醒来，屏幕下方出现半透明摇杆提示。走动 3 秒后提示消失（教学模式：做出来即消失，不用"确定"按钮）。
2. 走近第一个鸦片箱，出现"交互"按钮 → 按一下，角色扛起箱子。
3. 走近销烟池，交互 → 箱子倒入池中，池水冒泡、白烟升起（粒子特效），屏幕右上角计数 `鸦片 1/8`。
4. 重复 8 次，中间穿插 2 段林则徐 NPC 对话（`np_linzexu_pool1/2`），说明销烟的规模与意义。
5. 第 8 箱投入后，林则徐走近，触发最后一句话："**若鸦片一日未绝，本大臣一日不回。**" → 知识卡入袋。
6. 教学插片 Q：1 题选择题（虎门销烟发生在哪一年？）——教玩家"知识卡和测验长什么样"。

**场景 B：虎门威远炮台（C 即时战斗，约 6 分钟）**

1. 教学插片：武器切换。玩家默认持刀（`wp_dao`），按攻击键挥砍木桩，木桩破碎（打击感三件套首次登场：命中闪白 + 击退 + 像素碎屑）。
2. 教学插片：闪避。敌舰第一轮炮击落下（地面出现红圈预警），玩家必须翻滚躲开，否则掉血。
3. 教学插片：拾取与装备。击退第一批登陆英兵后掉落一把白色的弓（`wp_bow`），走近自动拾取，弹出装备提示，攻击方式变为远程。
4. **波次结构（共 3 波 + Boss）**
   - 波次 1：英军步兵 ×4（近战登陆兵，直线冲锋）
   - 波次 2：英军步兵 ×5 + 掷弹兵 ×2（远程抛物线）
   - 波次 3：英军军官 ×1（精英，带护盾，需闪避他的一次突刺）+ 步兵 ×4
   - **Boss：英军蒸汽炮舰（`en_boss_steamfrigate`）** — 停在炮台外侧海面，血条分两段。攻击方式：① 舷炮齐射（扇形弹幕，需躲到垛口后）② 投放登陆艇（召唤 2 名步兵）③ 舰首撞角冲滩（一次直线冲刺，躲开后炮舰卡在浅滩，露出弱点 8 秒）。
5. 血量降到 30% 时触发剧情：**弹药耗尽**。屏幕提示"炮弹已尽"，玩家只剩刀与弓。此时关天培触发独白，随后进入固定结局。
6. **历史性收束**：Boss 不会被击杀。最后一击由玩家打出后，炮舰退去，炮台已是残垣——关天培身中数创，画面静音、变灰，出现"1841.2.26 虎门"字样。**主角阵亡，自动切换到下一幕化身。**

#### 玩法与关卡流程

**场景 A：金田突围（C，约 5 分钟）**

- 玩家带 3 名太平军战士（可控 AI 友军），从村口向外突围。
- 波次：清军绿营（慢、血低、数量多）→ 清军骑兵（快、冲锋，需闪避）→ 清军把总（精英）。
- 目标不是"杀光"，而是**把 3 名友军带到地图右端**（保护目标）。这是本作第一次出现"护送"目标，教玩家"战友"的存在。
- 到达终点触发：洪秀全宣布起义，旗号"太平天国"升起。

**场景 B：天京经营（G 建设经营，约 6 分钟）**

这是全作第一个非战斗的轻度经营模块，机制刻意做得简单但**主题明确：资源永远不够**。

- 界面：三根分配条（粮草 / 兵员 / 民心），每月每个条需要分配点数，总点数固定为 6 点/月。
- 推进 8 个月，每月结算：
  - 粮草 < 2：兵员下降
  - 兵员 < 2：城墙脆弱度上升
  - 民心 < 2：出现逃亡事件，粮草与兵员同时下降
  - 三项都 ≥ 2：进入"盛世"，出现正面事件
- **设计要点**：总点数 6 点，恰好**无法**让三项长期都 ≥ 2。玩家必然要牺牲一项。这就是"农民阶级的局限性"——**不是不努力，是没有能力建立科学的社会制度。** 玩家会亲身感到"怎么分都不够"。
- 结束时给出评价：无论玩家怎么分，结算文案都是"天京的粮仓渐渐空了"。

**场景 C：天京守城（C 即时战斗，约 7 分钟）**

- 玩法：塔防式即时战斗混合——玩家在城墙上移动，操作两门城防炮（限时冷却），同时下城与攻入城内的敌军近战。
- 波次 4 波 + Boss。
- 第 4 波后城墙被轰开一个缺口，敌军涌入。
- **Boss：湘军 + 洋枪队联合部队（`en_boss_xiangarmy`）** — 表现为一名湘军统领（近战大刀，重甲）+ 洋枪队队长（远程火枪，伤害高但装填慢）。两人同场，需分而治之。
- 结局：城破后进入固定过场，李秀成被俘、就义；太平天国运动失败。

## 3.4 序章副本（3 个）

副本与剧情解耦，纯粹为战斗与刷装备服务。设计目标：单次 3—5 分钟，可重复，掉落随难度提升。三个副本的 ID、解锁幕、波次与掉落与 `game/public/data/dungeons/dungeons.json` 一一对应——**改设计必须同步改 JSON**。

### 3.4.1 副本 · 租界暗巷（`dg01_alley`）

| 项目 | 内容 |
| --- | --- |
| 解锁 | 通关第一幕；推荐等级 Lv3 |
| 地图 | 窄巷（`map_dg01_alley`，宽度是常规地图的一半） |
| 玩法 | C 即时战斗，3 波 + 精英 |
| 敌人 | 巡捕 ×3 → 巡捕 ×2 + 流氓打手 ×3 → 流氓打手 ×2 + 包打听精英 ×1 |
| 特殊机制 | **竹尖坑陷阱**（踩中掉血并减速 2 秒）、**铜锣诱敌**（打击铜锣把远处敌人引到陷阱区） |
| 掉落权重 | 白 45% / 蓝 40% / 紫 15% |
| 独特掉落 | `eq_acc_concession_blue_01` 蓝色饰品"租界通行证"（+移速） |

> 窄巷设计的用意：**把玩家的注意力从"跑位"转向"利用地形"**。竹尖坑与铜锣诱敌来自旧 Godot 项目已验证的设计，直接复用。

### 3.4.2 副本 · 广州城外匪寨（`dg02_bandit`）

| 项目 | 内容 |
| --- | --- |
| 解锁 | 通关第二幕；推荐等级 Lv5 |
| 地图 | 寨门广场 + 寨内高台（`map_dg02_bandit`） |
| 玩法 | C 即时战斗，4 波 + Boss |
| 敌人 | 匪兵成阵、弩手压阵，末波 Boss 匪寨头目（`en_boss_bandit_chief`） |
| 特殊机制 | **炮台防守**——寨门处有一门可用的大炮，玩家可操作它清一波，但只有 3 发 |
| 掉落权重 | 白 40% / 蓝 42% / 紫 18% |
| 独特掉落 | `eq_wp_dao_bandit_blue_01` 蓝色武器"匪寨大刀"（高攻低速） |

### 3.4.3 副本 · 沪上码头（`dg03_dock`）

| 项目 | 内容 |
| --- | --- |
| 解锁 | 通关第二幕；推荐等级 Lv6 |
| 地图 | 码头货场（`map_dg03_dock`）：货箱、吊机与汽灯 |
| 玩法 | C 即时战斗，4 波，无 Boss（末波为精英） |
| 敌人 | 帮会打手 ×4 → 打手 ×3 + 烟厂监工 ×2（远程） → 打手 ×4 + 监工 ×1 → 打手 ×2 + 码头把头精英 ×1 |
| 掉落权重 | 白 40% / 蓝 42% / 紫 18% |
| 独特掉落 | `eq_leg_dock_blue_01` 蓝色腿部"码头工装"（+移速） |

> **为什么有第三个副本**：副本全部挂在第一、二幕之后，而剧情要一路走到 1912——玩家在第三幕之后仍然需要一个"练级与补装场"，所以三个副本的解锁条件不跟着幕数往上抬；沪上码头同时把"码头 / 帮会 / 监工"这套上海意象提前立起来。此条与旧稿"只有 2 个副本"的偏差记为 D-7（见工程区 `game/README.md`）。

## 3.5 序章数值配置

| 项目 | 数值 |
| --- | --- |
| 玩家起始等级 | Lv1（HP 100 / ATK 10 / DEF 4 / 移速 72 px/s） |
| 序章结束预期等级 | Lv9—10（五幕打完的基础经验 3020，击杀经验另计） |
| 敌人等级带 | 普通 1—8 级，精英 3—9 级，Boss 4—10 级（随幕递进） |
| 单幕基础经验（通关结算） | 320（第一幕）/ 480（第二幕）/ 620（第三幕）/ 700（第四幕）/ 800（第五幕） |
| 击杀经验 | 杂兵 6 / 标准兵 10 / 远程兵 12 / 精英 45 / Boss 200（每杀一个结算一次） |
| 首通必给 | 第一幕 `eq_wp_bow_white_01` 白色弓；第二幕 `eq_leg_taiping_blue_01` 蓝色腿部；第三幕 `eq_wp_dao_dock_blue_01`；第四幕 `eq_wp_bow_blue_01`；第五幕 `eq_body_cloth_blue_01` |
| 紫色装备 | 五幕本身不保底紫装，紫装由副本产出（见 3.4） |
| 国运刻度 | 100（起始）→ 70 → 55 → 35 → 25 → 0（终局归零才收卷） |
| 玩家在序章可解锁武器 | 刀（初始）、弓（第一幕） |
| 序章教学覆盖 | 移动、交互、拾取、装备、近战、远程、闪避、护送、经营、抉择、知识问答 |

> **数值意图**：序章的难度曲线刻意"偏软"。史实上这五次都是失败，游戏里不应让玩家在操作上再受一次挫——**让玩家"赢下每一场战斗，却输掉整段历史"**，这个反差才是序章的情绪设计。基础经验 3020 + 击杀经验刚好把玩家送到 Lv9—10，既不"练废"也不"越级"。
